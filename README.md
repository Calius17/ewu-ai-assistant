# East West University AI Assistant

An educational web application that helps students explore East West University programs, tuition fees, scholarships, admission requirements, and campus information.

## Live Application

[https://ewu-ai-assistant.vercel.app](https://ewu-ai-assistant.vercel.app)

## Features

- AI chat assistant for common EWU questions
- Tuition fee calculator with waiver estimates
- Undergraduate programs directory
- Scholarship and waiver information
- Campus, transport, and admission guidance
- Bengali, Banglish, and English support

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- Node.js and Express
- Vercel Functions

## Run Locally

```powershell
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```powershell
npm run build
npm run lint
```
